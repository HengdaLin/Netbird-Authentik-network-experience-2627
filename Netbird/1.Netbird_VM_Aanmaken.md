# Technische Documentatie: VM `netbird` aanmaken (Proxmox)

**Doel:** Een Debian 13 VM op Proxmox opzetten waarop later NetBird (self-hosted) in Docker draait. NetBird wordt gekoppeld aan Authentik voor inloggen en groepen.

## 1. Status

| Onderdeel | Status |
| --- | --- |
| NAT-bridge `vmbr1` en Debian ISO | ✅ Klaar (zie `6.Proxmox_NAT_Netwerk.md`) |
| VM `102` aangemaakt | ✅ |
| Debian 13 geïnstalleerd | ✅ |
| Docker geïnstalleerd | ⏳ |
| NetBird geïnstalleerd | ⏳ Zie `2.Netbird_Installeren_OIDC.md` |

## 2. Specificaties

| Eigenschap | Waarde |
| --- | --- |
| VM ID | `102` |
| Naam / hostname | `netbird` |
| Besturingssysteem | Debian 13.7 'trixie' (netinst, geen desktop) |
| IP-adres | `10.50.0.11` |
| Netmask | `255.255.0.0` (/16) |
| Gateway | `10.50.0.1` (Proxmox-host, `vmbr1`) |
| DNS | `1.1.1.1` |
| CPU | 1 socket, 2 cores |
| Geheugen | `2048` MiB maximum, `1024` MiB minimum, ballooning aan |
| Schijf | 20 GiB op `local-lvm` (LVM-thin) |
| Netwerk | Bridge `vmbr1`, VirtIO |

NetBird raadt minstens 1 CPU en 2 GB RAM aan voor een self-hosted server. Daarom is 2 GB het maximum; het minimum van 1 GB geeft de host ruimte als het geheugen krap wordt.

> Controleer deze waarden tegen wat er werkelijk onder `102 → Hardware` staat en pas dit document aan als het afwijkt.

## 3. VM aanmaken (Proxmox webinterface)

Klik rechtsboven op **Create VM** (of kloon `101` en pas daarna hostname, IP, machine-ID en SSH-sleutels aan), met **Advanced** aangevinkt:

| Tab | Instelling |
| --- | --- |
| **General** | VM ID `102`, Name `netbird` |
| **OS** | ISO `debian-13.7.0-amd64-netinst.iso`, Type Linux |
| **System** | Standaard (i440fx, SeaBIOS, VirtIO SCSI single), **Qemu Agent** aan |
| **Disks** | 20 GiB, Storage `local-lvm`, **Discard** aan, **SSD emulation** aan, IO thread aan |
| **CPU** | Sockets `1`, Cores `2` |
| **Memory** | Memory `2048`, Minimum memory `1024`, Ballooning Device aan |
| **Network** | Bridge `vmbr1`, Model VirtIO |

Bij Confirm blijft **Start after created** uit.

> ⚠️ **Thin provisioning:** de pool `local-lvm` is gedeeld met andere VM's. Controleer regelmatig met `lvs` op de host (kolom `Data%`).

## 4. Debian installeren

Start de VM en open de **Console**. Kies **Install** en vul in:

| Scherm | Waarde |
| --- | --- |
| Language / Location / Locale | English / Belgium / `en_US.UTF-8` |
| Keyboard | American English |
| Netwerk | **Configure network manually** (geen DHCP) |
| IP address | `10.50.0.11` |
| Netmask | `255.255.0.0` |
| Gateway | `10.50.0.1` |
| Name server | `1.1.1.1` |
| Hostname | `netbird`, domain leeg |
| Root password / gebruiker | Sterke wachtwoorden, eigen gebruikersaccount |
| Time zone | Brussels |
| Partitioning | Guided - use entire disk, All files in one partition |
| Mirror | Belgium, `deb.debian.org`, geen proxy |
| **Software selection** | Alleen **SSH server** en **standard system utilities**; desktop en **web server** uit |
| GRUB | **Yes**, installeren op `/dev/sda` |

> ⚠️ **Geen webserver installeren.** NetBird gebruikt zelf poort 80 en 443 (via zijn proxy). Een Apache op dezelfde poort veroorzaakt een conflict. Gebruik in het softwarescherm de **spatiebalk** om te (de)selecteren en **Enter** alleen om te bevestigen.

### 4.1 Afronden

1. Bij **Installation complete** eerst `102 → Hardware → CD/DVD Drive → Edit` en **Do not use any media** kiezen.
2. Daarna in de console op **Continue** drukken.
3. Controleer onder `Options → Boot Order` dat `scsi0` aangevinkt is en boven `ide2` staat.

## 5. Instellingen voor beheer

Onder `Options`:

| Instelling | Waarde |
| --- | --- |
| Start at boot | **Yes** |
| Start/Shutdown order | `order=2` (start na `authentik`) |
| QEMU Guest Agent | Enabled |

## 6. Controle

Vanaf de Proxmox-host:

```bash
ssh <gebruiker>@10.50.0.11
```

In de VM:

```bash
ping -c 3 10.50.0.1
ping -c 3 1.1.1.1
ping -c 3 deb.debian.org
ping -c 3 10.50.0.10
hostname
systemctl get-default
```

Verwacht:

* Alle pings slagen (`10.50.0.10` pas zodra de VM `authentik` draait).
* `systemctl get-default` geeft `multi-user.target`.
* Er luistert niets op poort 80 of 443: `ss -tlnp | grep -E ':80|:443'` is leeg.

## 7. Docker installeren

```bash
su -
apt update && apt full-upgrade -y
apt install -y curl sudo qemu-guest-agent
curl -fsSL https://get.docker.com | sh
usermod -aG docker <gebruiker>
docker run --rm hello-world
```

Na `usermod` opnieuw inloggen. Controleer ook: `systemctl status fstrim.timer`.

## 8. Voorwaarden voor NetBird (voor later)

NetBird is nog niet geïnstalleerd. Voor een self-hosted installatie is het volgende nodig:

| Voorwaarde | Toelichting |
| --- | --- |
| Publiek bereikbare server | TCP 80 en 443 en UDP 3478 |
| Publiek domein | Moet naar deze server wijzen (bijvoorbeeld `netbird.<domein>`) |
| Authentik bereikbaar | Studenten loggen via hun browser in bij Authentik, dus ook Authentik heeft een domein nodig |
| Self-hosted | JWT group sync met Authentik werkt niet op NetBird Cloud |

De bereikbaarheid (port forwarding op de Proximus-modem, een VPS of een server van school) is nog niet beslist. Dit bepaalt hoe de PoC extern getest kan worden.

## 9. Troubleshooting

| Symptoom | Oorzaak | Oplossing |
| --- | --- | --- |
| Console blijft op *Booting from Hard Disk* | GRUB niet geïnstalleerd | VM stoppen en opnieuw installeren |
| Installer verschijnt niet | `ide2` niet aangevinkt bij Boot Order | `ide2` aanvinken, VM stoppen en starten |
| Installer start telkens opnieuw | ISO nog gekoppeld | CD/DVD op *Do not use any media* zetten |
| Geen internet in de VM | NAT niet actief | `iptables -t nat -L POSTROUTING -n` op de host |
| Poort 80 bezet | Webserver geïnstalleerd | `apt purge -y apache2` en `ss -tlnp` controleren |
| Desktop per ongeluk geïnstalleerd | Enter in plaats van spatiebalk | Opnieuw installeren (aanbevolen) of `apt purge` en `systemctl set-default multi-user.target` |
| Kloon heeft hetzelfde IP of dezelfde sleutels | Niet aangepast na klonen | Hostname, `/etc/network/interfaces`, `rm /etc/machine-id && systemd-machine-id-setup` en `dpkg-reconfigure openssh-server` |
