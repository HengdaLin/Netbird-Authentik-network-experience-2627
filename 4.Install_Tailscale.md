# Technische Documentatie: Tailscale op Proxmox VE (Remote toegang)

**Doel:** Proxmox VE (headless server via WiFi) veilig bereikbaar maken voor mezelf en een collega via Tailscale, zonder poorten open te zetten op de Proximus-modem.

## 1. Systeemspecificaties

* **Besturingssysteem:** Proxmox VE 9.2 (gebaseerd op Debian 'trixie')
* **Netwerkinterface:** `wlp3s0` (WiFi, statisch IP `192.168.128.10/23`)
* **VPN-oplossing:** Tailscale (WireGuard-gebaseerd mesh-VPN)
* **Tailscale IP-bereik:** `100.x.y.z` (wordt automatisch toegewezen)
* **Webinterface via Tailscale:** `https://<tailscale-ip>:8006`
* **SSH via Tailscale:** `ssh <gebruiker>@<tailscale-ip>`

## 2. Werking

Tailscale legt een versleutelde verbinding (tunnel) tussen apparaten die zijn ingelogd op dezelfde tailnet. De server hoeft daarvoor alleen uitgaand internet te hebben. Er is **geen port forwarding** op de Proximus-modem nodig en het lokale IP-adres blijft ongewijzigd.

Voorwaarden:

* De server heeft internetverbinding via WiFi (zie `2_Proxmox_WIFI.md`).
* De server blijft aan met een gesloten klep (zie `3_Proxmox_Lid_Switch.md`).
* Een Tailscale-account (gratis plan volstaat voor persoonlijk gebruik).

## 3. Installatie

Alle stappen worden uitgevoerd als `root` op de Proxmox-host.

### 3.1 Tailscale-repository toevoegen

Tailscale heeft een officiële apt-repository voor Debian Trixie. De codenaam `trixie` moet exact worden gebruikt.

```bash
apt-get update
apt-get install -y curl

curl -fsSL https://pkgs.tailscale.com/stable/debian/trixie.noarmor.gpg | tee /usr/share/keyrings/tailscale-archive-keyring.gpg >/dev/null
curl -fsSL https://pkgs.tailscale.com/stable/debian/trixie.tailscale-keyring.list | tee /etc/apt/sources.list.d/tailscale.list
```

### 3.2 Tailscale installeren

```bash
apt-get update
apt-get install -y tailscale
```

*Alternatief:* het officiële installatiescript `curl -fsSL https://tailscale.com/install.sh | sh` doet hetzelfde in één commando.

### 3.3 Verbinden met de tailnet

```bash
tailscale up
```

Er verschijnt een inloglink in de terminal. Open die op een ander apparaat en log in met het Tailscale-account. Na goedkeuring verschijnt de server in de admin console (`https://login.tailscale.com/admin/machines`).

### 3.4 Tailscale IP opvragen

```bash
tailscale ip -4
```

Dit IP-adres (begint met `100.`) wordt gebruikt om bij Proxmox te komen vanaf een apparaat met Tailscale.

### 3.5 Controleren

```bash
tailscale status
systemctl is-enabled tailscaled
systemctl status tailscaled
```

De service `tailscaled` moet `enabled` en `active (running)` zijn, zodat Tailscale na een reboot automatisch start.

## 4. Key expiry uitschakelen

Standaard verloopt de authenticatiesleutel van een apparaat na een bepaalde periode. Voor een server die op afstand wordt gebruikt moet dit uit, anders valt de server weg uit de tailnet en is er alleen fysiek toegang mogelijk.

1. Ga naar `https://login.tailscale.com/admin/machines`.
2. Klik bij de machine (`proxmox`) op de drie puntjes.
3. Kies **Disable key expiry**.

## 5. Toegang voor een collega

### Optie A: machine delen (aanbevolen)

De collega gebruikt een eigen Tailscale-account en ziet alleen deze ene machine, niet de rest van de tailnet.

1. Open de admin console, ga naar **Machines**.
2. Klik bij `proxmox` op de drie puntjes en kies **Share**.
3. Genereer een uitnodigingslink en stuur die naar de collega.
4. De collega installeert Tailscale, logt in met een eigen account en accepteert de uitnodiging.
5. De collega kan daarna verbinden via `https://<tailscale-ip>:8006` en SSH.

### Optie B: collega toevoegen aan de tailnet

Geeft meer toegang dan nodig, tenzij ACL's zijn ingesteld. Alleen gebruiken voor een gedeelde projecttailnet.

| Optie | Toegang collega | Aanbevolen |
| --- | --- | --- |
| A: Machine delen | Alleen de Proxmox-server | ✅ Ja |
| B: Toevoegen aan tailnet | Alle apparaten in de tailnet (tenzij ACL's) | Alleen met ACL's |

## 6. Eigen Proxmox-account voor de collega

Het `root`-wachtwoord wordt **nooit** gedeeld. In plaats daarvan:

1. Webinterface: **Datacenter, Permissions, Users, Add**.
2. Realm: **Proxmox VE authentication server** (`pve`), met gebruikersnaam en wachtwoord.
3. **Datacenter, Permissions, Add, User Permission**: path `/`, de nieuwe gebruiker en een rol.

| Rol | Gebruik |
| --- | --- |
| `PVEVMAdmin` | VM's en containers beheren (aanbevolen) |
| `PVEVMUser` | VM's gebruiken (starten, stoppen, console) |
| `Administrator` | Volledige beheerrechten (alleen indien echt nodig) |

Een Linux-account op de host voor SSH is alleen nodig als de collega de shell van de host moet gebruiken. Voor VM-beheer volstaat de webinterface.

## 7. Test

Vanaf een ander apparaat waarop Tailscale actief is (laptop of telefoon):

```bash
ping <tailscale-ip>
```

Daarna in de browser `https://<tailscale-ip>:8006` openen en inloggen. De waarschuwing over het zelfondertekende certificaat is normaal bij Proxmox.

Test ook met een gesloten laptopklep en met WiFi als enige netwerkverbinding.

## 8. Handige commando's

| Doel | Commando |
| --- | --- |
| Status en verbonden apparaten | `tailscale status` |
| Eigen Tailscale IPv4 | `tailscale ip -4` |
| Verbinding verbreken | `tailscale down` |
| Opnieuw verbinden | `tailscale up` |
| Verbinding testen naar peer | `tailscale ping <apparaat>` |
| Service herstarten | `systemctl restart tailscaled` |
| Logs bekijken | `journalctl -u tailscaled -e` |
| Tailscale updaten | `apt-get update && apt-get install --only-upgrade tailscale` |

## 9. Troubleshooting

| Symptoom | Controle | Oplossing |
| --- | --- | --- |
| Repository geeft 404 | `cat /etc/apt/sources.list.d/tailscale.list` | Controleer dat `trixie` in de URL staat, geen `13` |
| `tailscale up` geeft geen link | `systemctl status tailscaled` | `systemctl restart tailscaled` en opnieuw proberen |
| Server verschijnt niet in admin console | `ping 8.8.8.8` | Controleer WiFi (zie `2_Proxmox_WIFI.md`) |
| Server valt na tijd weg uit tailnet | Admin console, key expiry | **Disable key expiry** (sectie 4) |
| Collega kan niet verbinden | Heeft hij de uitnodiging geaccepteerd? | Controleer sharing in de admin console |
| Webinterface niet bereikbaar via Tailscale IP | `ss -tlnp \| grep 8006` | Controleer dat `pveproxy` draait: `systemctl status pveproxy` |
| Verbinding traag of onstabiel | `iw dev wlp3s0 get power_save` | Power save uitzetten (zie document 3) |

## 10. Beveiligingsaanbevelingen

* Deel het `root`-wachtwoord niet; gebruik eigen Proxmox-accounts (sectie 6).
* Schakel twee-factor-authenticatie in op het Tailscale-account en op de Proxmox-accounts.
* Geef de collega de minimaal benodigde rol.
* Deel de uitnodigingslink alleen met de beoogde persoon en trek de toegang in via de admin console zodra die niet meer nodig is.
* Controleer regelmatig welke apparaten in de admin console staan.

## 11. Verwijderen (indien nodig)

```bash
tailscale down
apt-get purge -y tailscale
rm /etc/apt/sources.list.d/tailscale.list
rm /usr/share/keyrings/tailscale-archive-keyring.gpg
```

Verwijder daarna ook de machine in de admin console.

## 12. Samenvatting van de wijzigingen

| Onderdeel | Wijziging |
| --- | --- |
| `/etc/apt/sources.list.d/tailscale.list` | Tailscale-repository voor Trixie toegevoegd |
| Pakket `tailscale` | Geïnstalleerd, service `tailscaled` actief en enabled |
| Tailscale admin console | Machine toegevoegd, key expiry uitgeschakeld |
| Collega | Machine gedeeld via Share-uitnodiging |
| Proxmox-gebruikers | Eigen account voor de collega met beperkte rol |
