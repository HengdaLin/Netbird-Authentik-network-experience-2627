# Technische Documentatie: Proxmox VE Lid Switch Fix (SSH bij gesloten klep)

**Doel:** Zorgen dat de ThinkPad (Proxmox VE, headless server via WiFi) bereikbaar blijft via SSH en de webinterface wanneer de laptopklep gesloten is. Dit document vervangt en vult document 3 (Lid Switch) aan.

## 1. Probleem

Na het dichtklappen van de klep ging de laptop in slaapstand (suspend). Hierdoor viel ook de WiFi-kaart (`wlp3s0`) weg en was de server niet meer bereikbaar via SSH (`192.168.128.10`) of de webinterface (`https://192.168.128.10:8006`). Na het openen van de klep werd de laptop weer wakker.

## 2. Oorzaak

* In `/etc/systemd/logind.conf` waren de instellingen wel op `ignore` gezet, maar het hekje (`#`) stond nog voor de regels. Daardoor waren ze uitgecommentarieerd en dus niet actief.
* De regel `HandleLidSwitchDocked` ontbrak in de oorspronkelijke documentatie.
* Er was geen tweede beveiliging tegen slaapstand: de sleep-targets van systemd waren niet geblokkeerd.
* De WiFi-kaart kan met een gesloten klep in een energiespaarstand (power save) gaan, wat SSH traag kan maken of kan laten wegvallen.

## 3. Oplossing

Alle stappen zijn uitgevoerd als `root` op de Proxmox-host.

### 3.1 Controleren van de actieve configuratie

```bash
systemd-analyze cat-config systemd/logind.conf | grep -i lid
```

Regels die met `#` beginnen zijn niet actief. In dit geval stonden alle regels uitgecommentarieerd.

### 3.2 Lid-instellingen activeren (`/etc/systemd/logind.conf`)

Het hekje verwijderen en de waarde op `ignore` zetten, in één commando:

```bash
sed -i -E 's/^#?(HandleLidSwitch|HandleLidSwitchExternalPower|HandleLidSwitchDocked)=.*/\1=ignore/' /etc/systemd/logind.conf
```

Controle:

```bash
grep -E '^HandleLid' /etc/systemd/logind.conf
```

Verwacht resultaat (zonder `#`):

```text
HandleLidSwitch=ignore
HandleLidSwitchExternalPower=ignore
HandleLidSwitchDocked=ignore
```

| Instelling | Betekenis | Waarde |
| --- | --- | --- |
| `HandleLidSwitch` | Klep dicht op batterij | `ignore` |
| `HandleLidSwitchExternalPower` | Klep dicht met netstroom | `ignore` |
| `HandleLidSwitchDocked` | Klep dicht in dock of met extern scherm | `ignore` |

> ⚠️ De waarde `lock` werkt niet op Proxmox, omdat er geen grafische desktopomgeving is.

### 3.3 Slaapstand volledig blokkeren

De sleep-targets worden gemaskeerd (gekoppeld aan `/dev/null`), zodat niets in het systeem de laptop nog in suspend of hibernate kan zetten:

```bash
systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target
```

Ongedaan maken, indien ooit nodig:

```bash
systemctl unmask sleep.target suspend.target hibernate.target hybrid-sleep.target
```

### 3.4 WiFi power saving uitschakelen

Het pakket `iw` was niet geïnstalleerd (`iw: command not found`):

```bash
apt update && apt install -y iw
iw dev wlp3s0 set power_save off
iw dev wlp3s0 get power_save
```

Verwacht resultaat: `Power save: off`.

Om dit na een reboot te behouden, is de volgende regel toegevoegd aan het `wlp3s0`-blok in `/etc/network/interfaces`:

```text
auto wlp3s0
iface wlp3s0 inet static
        address 192.168.128.10/23
        gateway 192.168.128.1
        wpa-conf /etc/wpa_supplicant/wpa_supplicant.conf
        post-up iw dev wlp3s0 set power_save off
```

### 3.5 Volledige herstart

```bash
reboot
```

Een volledige reboot is betrouwbaarder dan alleen `systemctl restart systemd-logind`.

## 4. Test

1. Na de herstart niet inloggen op de fysieke terminal, of `exit` typen zodat de `proxmox login:` prompt zichtbaar is.
2. Klep sluiten.
3. Vanaf een ander apparaat testen:

```bash
ping 192.168.128.10
ssh root@192.168.128.10
```

**Resultaat:** de server blijft bereikbaar met een gesloten klep. ✅

## 5. Troubleshooting

| Symptoom | Controle | Oplossing |
| --- | --- | --- |
| Server valt weg na klep sluiten | `grep -E '^HandleLid' /etc/systemd/logind.conf` | Hekjes verwijderen, waarde `ignore` |
| Instelling lijkt niet te werken | `systemd-analyze cat-config systemd/logind.conf \| grep -i lid` | Controleer of de regels onder `[Login]` staan |
| Ping wordt traag of valt soms weg | `iw dev wlp3s0 get power_save` | `iw dev wlp3s0 set power_save off` en `post-up` regel toevoegen |
| `iw: command not found` | | `apt install -y iw` |
| Oorzaak onduidelijk | `journalctl -b -1 \| grep -iE "lid\|suspend\|sleep" \| tail -20` | Logs van de vorige boot bekijken |
| WiFi geblokkeerd | `rfkill list` | `rfkill unblock wifi` |

## 6. Veiligheidsinstructie

Omdat de klep geen slaapstand of lock-scherm meer activeert, blijft een ingelogde sessie op de fysieke terminal openstaan. Voordat de klep wordt gesloten:

1. Typ `exit` (of **Ctrl + D**).
2. Controleer dat de `proxmox login:` prompt zichtbaar is.
3. Sluit de klep. Het scherm gaat uit, maar het systeem, SSH, de webinterface en de virtuele machines blijven draaien.

## 7. Samenvatting van de wijzigingen

| Bestand of onderdeel | Wijziging |
| --- | --- |
| `/etc/systemd/logind.conf` | Drie `HandleLidSwitch*` regels actief op `ignore` |
| systemd targets | `sleep`, `suspend`, `hibernate` en `hybrid-sleep` gemaskeerd |
| Pakket `iw` | Geïnstalleerd |
| `/etc/network/interfaces` | `post-up iw dev wlp3s0 set power_save off` onder `wlp3s0` |
