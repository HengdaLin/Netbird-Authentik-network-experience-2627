# Technische Documentatie: Proxmox VE Energiebeheer (Lid Switch)

## 1. Doel
De ThinkPad functioneert als een headless server. Standaard gaat de laptop in slaapstand (suspend) wanneer de klep (lid) wordt gesloten. Om te zorgen dat de server actief en bereikbaar blijft via het netwerk met een gesloten klep, moet het standaard energiebeheer van Linux (`systemd`) worden aangepast.

## 2. Configuratiebestand Aanpassen
Het gedrag van de klep wordt geregeld in het bestand `logind.conf`.

- **Bestand openen:** `nano /etc/systemd/logind.conf`
- **Aanpassingen:** Zoek de volgende regels, verwijder het hekje (`#`) aan het begin om ze te activeren, en wijzig de waarde naar `ignore`:

```text
HandleLidSwitch=ignore
HandleLidSwitchExternalPower=ignore
```

Let op: De instelling `lock` werkt niet naar behoren op Proxmox, omdat dit een grafische desktopomgeving (GUI) verwacht die op een headless server ontbreekt.

## 3. Wijzigingen Activeren
Sla het bestand op (**Ctrl + O, Enter, Ctrl + X**) en herstart de logind-dienst om de wijzigingen direct door te voeren zonder de server te herstarten:

```Bash
systemctl restart systemd-logind
```

## 4. Veiligheidsinstructies (Server Vergrendelen)
Omdat de klep nu geen slaapstand of grafisch lock-scherm meer activeert, blijft de fysieke terminal openstaan als er nog een gebruiker is ingelogd.

Voer altijd de volgende stap uit voordat de laptopklep wordt gesloten:

Typ `exit` in de commandoregel (of gebruik **Ctrl + D**).

Verifieer dat het startscherm met de `proxmox login:` prompt weer in beeld staat.

Sluit de klep. Het scherm gaat fysiek uit om stroom te besparen, maar het systeem en de netwerkverbindingen (Web GUI, SSH, virtuele machines) blijven 100% draaien.
