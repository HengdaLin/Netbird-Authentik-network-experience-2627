# Technische Documentatie: Proxmox VE Standalone via WiFi

**Doel:** Proxmox VE (gebaseerd op Debian) configureren om uitsluitend via een draadloze netwerkkaart (WiFi) te communiceren, onafhankelijk van een fysieke ethernetkabel, met behoud van een statisch IP-adres voor de webinterface.

## 1. Systeemspecificaties

* **Besturingssysteem:** Proxmox VE 9.2 (gebaseerd op Debian 'trixie')
* **Draadloze interface (WLAN):** `wlp3s0`
* **Pakketten voor WiFi:** `wpasupplicant`, `iw`
* **Statisch IP-adres (Proxmox GUI):** `192.168.128.10`
* **Subnetmasker:** `/23` (vergelijkbaar met `255.255.254.0`)
* **Default Gateway (router):** `192.168.128.1`
* **Webinterface URL:** `https://192.168.128.10:8006`

## 2. Voorwaarden

De installatiewizard van Proxmox vraagt niet om WiFi-gegevens en `wpasupplicant` is niet standaard meegeleverd. Voor de eerste configuratie is daarom **eenmalig een netwerkkabel nodig**:

1. Sluit de laptop via `nic0` direct aan op een vrije poort van de Proximus-modem (niet via een Windows-pc of netwerkbrug).
2. Start Proxmox opnieuw op en test de verbinding: `ping 8.8.8.8`.
3. Installeer na de repository-aanpassing (sectie 3) de benodigde pakketten.
4. Na het werkend krijgen van WiFi kan de kabel permanent worden verwijderd.

## 3. Systeemrepositories

Proxmox zoekt standaard naar de betaalde 'Enterprise' update-servers, wat een `401 Unauthorized` geeft zonder abonnement. Om `wpasupplicant` te kunnen installeren zonder licentiefouten of versieconflicten zijn de pakketbronnen afgestemd op de 'trixie' release met de gratis no-subscription repository.

**Enterprise-repositories uitschakelen.** Controleer eerst welke bestanden aanwezig zijn:

```bash
ls /etc/apt/sources.list.d/
```

Geef de bestanden met `enterprise` in de naam een andere extensie, zodat apt ze negeert. Voorbeeld (pas de bestandsnaam aan op wat `ls` toont):

```bash
mv /etc/apt/sources.list.d/pve-enterprise.sources /etc/apt/sources.list.d/pve-enterprise.sources.disabled
```

**Bestand `/etc/apt/sources.list`:**

```text
deb http://download.proxmox.com/debian/pve trixie pve-no-subscription
deb http://deb.debian.org/debian trixie main
```

**Pakketten installeren:**

```bash
apt update
apt install -y wpasupplicant iw
```

## 4. WiFi-authenticatie (`/etc/wpa_supplicant/wpa_supplicant.conf`)

Dit bestand bevat de inloggegevens van het draadloze netwerk.

*Aangemaakt via het commando:*

```bash
wpa_passphrase "SSID" "WACHTWOORD" > /etc/wpa_supplicant/wpa_supplicant.conf
```

Resultaat (voorbeeld):

```text
network={
        ssid="<SSID>"
        #psk="<WACHTWOORD IN PLAINTEXT>"
        psk=<hash>
}
```

> ⚠️ **Let op:** `wpa_passphrase` zet het echte wachtwoord **in leesbare tekst** als commentaarregel (`#psk=`) in het bestand. De `psk=` hash eronder is geen echte versleuteling: wie de hash heeft, kan er nog steeds mee op het netwerk. Verwijder daarom de commentaarregel en beperk de rechten:

```bash
sed -i '/#psk=/d' /etc/wpa_supplicant/wpa_supplicant.conf
chmod 600 /etc/wpa_supplicant/wpa_supplicant.conf
```

Deel dit bestand of de hash nooit (bijvoorbeeld niet in documentatie, chats of repositories).

## 5. Netwerkconfiguratie (`/etc/network/interfaces`)

Dit is de kern van de netwerkroutering.

> ⚠️ **Belangrijke architectuurkeuze:** Linux (en dus Proxmox) staat standaard niet toe dat een draadloze netwerkkaart (`wlp3s0`) als 'poort' wordt toegewezen aan een netwerkbrug (`vmbr0`). Om fatale crashes van de netwerkdienst te voorkomen, heeft de WiFi-kaart direct het statische IP gekregen en zijn er geen poorten toegewezen aan `vmbr0`.

```text
auto lo
iface lo inet loopback

# 1. WiFi-kaart (direct verbonden met lokaal netwerk en internet)
auto wlp3s0
iface wlp3s0 inet static
        address 192.168.128.10/23
        gateway 192.168.128.1
        wpa-conf /etc/wpa_supplicant/wpa_supplicant.conf
        post-up iw dev wlp3s0 set power_save off

# 2. Virtuele netwerkbrug (leeg gelaten om conflicten met WiFi te voorkomen)
auto vmbr0
iface vmbr0 inet manual
        bridge-ports none
        bridge-stp off
        bridge-fd 0

# 3. Bekabelde interfaces (uitgeschakeld/handmatig)
iface nic0 inet manual
iface nic1 inet manual

source /etc/network/interfaces.d/*
```

De regel `post-up iw dev wlp3s0 set power_save off` schakelt WiFi power saving permanent uit. Dat voorkomt dat de verbinding traag wordt of wegvalt bij een gesloten laptopklep (zie `3_Proxmox_Lid_Switch.md`).

### Beperking: VM's en containers

Omdat `vmbr0` geen poorten heeft, hebben virtuele machines en containers die op `vmbr0` zijn aangesloten **geen verbinding met het lokale netwerk of internet**. De host zelf is wel bereikbaar. Wil je VM's toegang geven, dan is een NAT-configuratie (masquerade via `wlp3s0`) of een andere netwerkopzet nodig.

## 6. Handige beheercommando's

Mocht de verbinding in de toekomst haperen of wil je een ander WiFi-netwerk instellen, gebruik dan deze commando's:

* **Netwerkstatus bekijken:** `ip a` (IP en interfaces) of `ip route` (gateway routing).
* **Route handmatig toevoegen:** `ip route add default via 192.168.128.1`
* **WiFi-kaart geforceerd herstarten:** `ifdown wlp3s0` gevolgd door `ifup wlp3s0`.
* **Hardware-blokkades checken (vliegtuigstand):** `rfkill list` (opheffen via `rfkill unblock wifi`).
* **Power saving status controleren:** `iw dev wlp3s0 get power_save` (verwacht `Power save: off`).
* **Volledige netwerkdienst herstarten:** `systemctl restart networking`.
* **Verbinding testen:** `ping 8.8.8.8`
