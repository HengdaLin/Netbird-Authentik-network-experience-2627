# Technische Documentatie: Proxmox VE Standalone via WiFi

**Doel:** Proxmox VE (gebaseerd op Debian) configureren om uitsluitend via een draadloze netwerkkaart (WiFi) te communiceren, onafhankelijk van een fysieke ethernetkabel, met behoud van een statisch IP-adres voor de webinterface.

## 1. Systeemspecificaties
* **Besturingssysteem:** Proxmox VE (gebaseerd op Debian 'trixie')
* **Draadloze interface (WLAN):** `wlp3s0`
* **Pakketbeheerder voor WiFi:** `wpasupplicant`
* **Statisch IP-adres (Proxmox GUI):** `192.168.128.10`
* **Subnetmasker:** `/23` (vergelijkbaar met `255.255.254.0`)
* **Default Gateway (Router):** `192.168.128.1`
* **Webinterface URL:** `https://192.168.128.10:8006`

---

## 2. Systeemrepositories (`/etc/apt/sources.list`)
Om `wpasupplicant` te kunnen installeren zonder licentiefouten (`401 Unauthorized`) of versie-conflicten (`Unsatisfied dependencies`), zijn de pakketbronnen afgestemd op de 'trixie' release, zonder de enterprise-repositories.

```text
deb http://download.proxmox.com/debian/pve trixie pve-no-subscription
deb http://deb.debian.org/debian trixie main
```

---

## 3. WiFi Authenticatie (`/etc/wpa_supplicant/wpa_supplicant.conf`)
Dit bestand bevat de versleutelde inloggegevens van het draadloze netwerk. Het netwerk wachtwoord wordt in een versleutelde hash opgeslagen.
*Aangemaakt via het commando:* `wpa_passphrase "SSID" "WACHTWOORD" > /etc/wpa_supplicant/wpa_supplicant.conf`

```text
network={
        ssid="VerrySecurePasswordJustTrustMe"
        #psk="admin"
        psk=8asdasd2h8sda20k... (versleutelde hash)
}
```

---

## 4. Netwerkconfiguratie (`/etc/network/interfaces`)
Dit is de kern van de netwerkroutering. 
> ⚠️ **Belangrijke architectuurkeuze:** Linux (en dus Proxmox) staat standaard niet toe dat een draadloze netwerkkaart (`wlp3s0`) als 'poort' wordt toegewezen aan een netwerkbrug (`vmbr0`). Om fatale crashes van de netwerkdienst te voorkomen, heeft de WiFi-kaart direct het statische IP gekregen, en zijn er geen poorten meer toegewezen aan `vmbr0`.

```text
auto lo
iface lo inet loopback

# 1. WiFi-kaart (Direct verbonden met lokaal netwerk & internet)
auto wlp3s0
iface wlp3s0 inet static
        address 192.168.128.10/23
        gateway 192.168.128.1
        wpa-conf /etc/wpa_supplicant/wpa_supplicant.conf

# 2. Virtuele netwerkbrug (Leeg gelaten om conflicten met WiFi te voorkomen)
auto vmbr0
iface vmbr0 inet manual
        bridge-ports none
        bridge-stp off
        bridge-fd 0

# 3. Bekabelde interfaces (Uitgeschakeld/handmatig)
iface nic0 inet manual
iface nic1 inet manual

source /etc/network/interfaces.d/*
```

## 5. Handige Beheercommando's
Mocht de verbinding in de toekomst haperen of mocht je een ander WiFi-netwerk willen instellen, gebruik dan deze commando's:

* **Netwerkstatus bekijken:** `ip a` (IP en interfaces checken) of `ip route` (Gateway routing checken).
* **Route handmatig toevoegen:** `ip route add default via 192.168.128.1`
* **WiFi-kaart geforceerd herstarten:** `ifdown wlp3s0` gevolgd door `ifup wlp3s0`.
* **Hardware-blokkades checken (Vliegtuigstand):** `rfkill list` (opheffen via `rfkill unblock wifi`).
* **Volledige netwerkdienst herstarten:** `systemctl restart networking`.
