# Technische Documentatie: VM `authentik` aanmaken (Proxmox)

**Doel:** Een Debian 13 VM op Proxmox opzetten waarop later Authentik (identity provider) in Docker draait. Onderdeel van de PoC voor Network Experience, los van de bestaande Authentik/NetBird-omgeving van school.

## 1. Status

| Onderdeel | Status |
| --- | --- |
| NAT-bridge `vmbr1` en Debian ISO | ✅ Klaar (zie `6.Proxmox_NAT_Netwerk.md`) |
| VM `101` aangemaakt | ✅ |
| Debian 13 geïnstalleerd | ✅ (bevestigen met de SSH-test in sectie 6) |
| Docker geïnstalleerd | ⏳ |
| Authentik geïnstalleerd | ⏳ Zie `2.Authentik_Installeren.md` |

## 2. Specificaties

| Eigenschap | Waarde |
| --- | --- |
| VM ID | `101` |
| Naam / hostname | `authentik` |
| Besturingssysteem | Debian 13.7 'trixie' (netinst, geen desktop) |
| IP-adres | `10.50.0.10` |
| Netmask | `255.255.0.0` (/16) |
| Gateway | `10.50.0.1` (Proxmox-host, `vmbr1`) |
| DNS | `1.1.1.1` |
| CPU | 1 socket, 2 cores (type `x86-64-v2-AES`) |
| Geheugen | `3072` MiB maximum, `1536` MiB minimum, ballooning aan |
| Schijf | 20 GiB op `local-lvm` (LVM-thin) |
| Netwerk | Bridge `vmbr1`, VirtIO |

Authentik vraagt minstens 2 CPU-cores en 2 GB RAM. Het minimum van 1536 MiB mag niet lager, anders kan de database door een OOM-fout stoppen.

> Controleer deze waarden tegen wat er werkelijk onder `101 → Hardware` staat en pas dit document aan als het afwijkt.

## 3. VM aanmaken (Proxmox webinterface)

Klik rechtsboven op **Create VM**, met **Advanced** aangevinkt:

| Tab | Instelling |
| --- | --- |
| **General** | VM ID `101`, Name `authentik` |
| **OS** | ISO `debian-13.7.0-amd64-netinst.iso`, Type Linux |
| **System** | Standaard (i440fx, SeaBIOS, VirtIO SCSI single), **Qemu Agent** aan |
| **Disks** | 20 GiB, Storage `local-lvm`, **Discard** aan, **SSD emulation** aan, IO thread aan, Cache Default (No cache) |
| **CPU** | Sockets `1`, Cores `2` |
| **Memory** | Memory `3072`, Minimum memory `1536`, Ballooning Device aan |
| **Network** | Bridge `vmbr1`, Model VirtIO |

Bij Confirm blijft **Start after created** uit.

### Waarom deze keuzes

| Instelling | Reden |
| --- | --- |
| Ballooning (min/max) | Ongebruikt geheugen gaat terug naar de host als die onder druk staat |
| Discard + SSD emulation | De VM geeft vrijgekomen ruimte terug aan de thin pool en schrijft minder onnodig naar de NVMe |
| 1 socket | Meerdere sockets bieden een VM geen voordeel; cores volstaan |

> ⚠️ **Thin provisioning:** `local-lvm` is een gedeelde thin pool. Het is mogelijk meer schijfruimte toe te wijzen dan er fysiek is. Controleer regelmatig met `lvs` op de host (kolom `Data%`); een volle pool veroorzaakt corruptie.

## 4. Debian installeren

Start de VM en open de **Console**. Kies **Install** (de tekstversie) en vul in:

| Scherm | Waarde |
| --- | --- |
| Language / Location / Locale | English / Belgium / `en_US.UTF-8` |
| Keyboard | American English |
| Netwerk | DHCP mislukt (geen DHCP-server): **Configure network manually** |
| IP address | `10.50.0.10` |
| Netmask | `255.255.0.0` |
| Gateway | `10.50.0.1` |
| Name server | `1.1.1.1` |
| Hostname | `authentik`, domain leeg |
| Root password / gebruiker | Sterke wachtwoorden, eigen gebruikersaccount |
| Time zone | Brussels |
| Partitioning | Guided - use entire disk, All files in one partition |
| Mirror | Belgium, `deb.debian.org`, geen proxy |
| Popularity contest | No |
| **Software selection** | Alleen **SSH server** en **standard system utilities** (met de **spatiebalk**); desktop en **web server** uit |
| GRUB | **Yes**, installeren op `/dev/sda` |

> ⚠️ In het scherm van de software-selectie vinkt de **spatiebalk** een optie aan of uit. **Enter** bevestigt het hele scherm. Een webserver zou poort 80 bezetten en een desktop kost onnodig RAM en schijfruimte.

### 4.1 Afronden (belangrijk)

Bij **Installation complete** nog **niet** op Continue drukken:

1. Ga naar `101 → Hardware → CD/DVD Drive → Edit` en kies **Do not use any media**.
2. Druk daarna in de console op **Continue**.
3. Controleer onder `Options → Boot Order` dat `scsi0` aangevinkt is en boven `ide2` staat.

## 6. Controle

Vanaf de Proxmox-host:

```bash
ssh <gebruiker>@10.50.0.10
```

In de VM:

```bash
ping -c 3 10.50.0.1
ping -c 3 1.1.1.1
ping -c 3 deb.debian.org
hostname
systemctl get-default
free -h
df -h
```

Verwacht:

* Alle pings slagen.
* `systemctl get-default` geeft `multi-user.target` (geen desktop).
* Het geheugen en de schijf zijn zoals ingesteld.

## 7. Docker installeren

```bash
su -
apt update && apt full-upgrade -y
apt install -y curl sudo qemu-guest-agent
curl -fsSL https://get.docker.com | sh
usermod -aG docker <gebruiker>
docker run --rm hello-world
```

Na `usermod` opnieuw inloggen, zodat de groepswijziging actief wordt. Controleer ook de wekelijkse TRIM:

```bash
systemctl status fstrim.timer
```

Staat hij niet op `active (waiting)`, dan: `systemctl enable --now fstrim.timer`.

## 8. Snapshot

Maak vóór de Authentik-installatie een snapshot (`101 → Snapshots → Take Snapshot`, bijvoorbeeld `basis-docker`). Zo is de VM in één minuut terug te zetten.

## 9. Troubleshooting

| Symptoom | Oorzaak | Oplossing |
| --- | --- | --- |
| Console blijft op *Booting from Hard Disk* | GRUB niet geïnstalleerd of installatie niet afgemaakt | VM stoppen en Debian opnieuw installeren |
| Installer verschijnt niet bij starten | Bij `Options → Boot Order` staat `ide2` niet aangevinkt | `ide2` aanvinken, VM volledig stoppen en opnieuw starten |
| Installer start telkens opnieuw | ISO nog gekoppeld | CD/DVD op *Do not use any media* zetten |
| Reset of Shutdown doet niets | VM hangt | **Stop** (pijltje naast Shutdown) gebruiken |
| Bootvolgorde-wijziging heeft geen effect | Reset volstaat niet | VM volledig stoppen en starten |
| Geen internet in de VM | NAT niet actief of verkeerde gateway | Op de host `iptables -t nat -L POSTROUTING -n`; in de VM gateway `10.50.0.1` controleren |
| `ping` werkt, `deb.debian.org` niet | DNS | `nameserver 1.1.1.1` in `/etc/resolv.conf` |
| Per ongeluk desktop of webserver geïnstalleerd | Enter in plaats van spatiebalk | Opnieuw installeren (aanbevolen) of `apt purge` en `systemctl set-default multi-user.target` |
