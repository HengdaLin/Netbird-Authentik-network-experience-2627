# Technische Documentatie: Proxmox VE Installatie

## 1. Systeemspecificaties

| Component | Specificatie |
| --- | --- |
| **Systeem** | Lenovo ThinkPad E14 Gen 2 |
| **Processor** | AMD Ryzen 5 4500U (Integrated Graphics) |
| **Geheugen** | 8 GB RAM |
| **Netwerk (NIC0)** | Realtek r8169 (Fysieke netwerkpoort) |
| **Netwerk (NIC1)** | Intel iwlwifi (Draadloze netwerkkaart) |
| **Opslag** | Interne NVMe SSD (`/dev/nvme0n1`) |

## 2. Voorbereiding Installatiemedia (Host: Windows)

* **Software:** Rufus Portable & Proxmox VE ISO Installer.
* **Doelmedium:** 8GB USB-stick.
* **Configuratie Rufus:**
* Boot selection: Proxmox ISO geselecteerd via de `SELECT` knop.
* Schrijfmethode: Geforceerd naar **Write in DD Image mode** (cruciaal om vastlopers tijdens de Proxmox setup te voorkomen).



## 3. Bootproces

1. Systeem herstart met de USB-stick ingeplugd.
2. Via de **F12-toets** tijdens het Lenovo-logo het bootmenu geopend.
3. Opstarten vanaf de USB-stick geselecteerd.
4. In het opstartscherm gekozen voor **Install Proxmox VE (Graphical)**.

## 4. Proxmox VE Setup Configuratie

* **Target Harddisk:** `/dev/nvme0n1` geselecteerd als doelschijf (volledige wipe van de bestaande Windows/Fedora dual-boot).
* **Locatie & Tijd:** Country ingesteld op Belgium (Europe/Brussels).
* **Authenticatie:** Beveiligd `root` wachtwoord ingesteld en e-mailadres (`hengda...`) opgegeven voor systeemnotificaties.

## 5. Netwerkconfiguratie (Afgestemd op Proximus HomeGateway)

De automatische netwerkinstellingen zijn handmatig overschreven om te functioneren binnen het bredere `/23` subnet van de Proximus Internet Box. Het IP-adres is buiten de automatische DHCP-pool (`192.168.129.x`) geplaatst.

| Parameter | Ingestelde Waarde |
| --- | --- |
| **Management Interface** | `nic1` (WiFi - Let op: vereist handmatige command-line configuratie na reboot) |
| **Hostname (FQDN)** | `proxmox.local` |
| **IP Address (CIDR)** | `192.168.128.10/23` (Statisch IP-adres voor de server) |
| **Gateway** | `192.168.128.1` (IP van Proximus modem) |
| **DNS Server** | `192.168.128.1` |

## 6. Installatie & Afronding

* Instellingen definitief geverifieerd in het Summary-scherm.
* Installatie gestart via de **Install** knop.
* Optie **Automatically reboot after successful installation** geactiveerd.
* **Post-installatie actie:** Installatiemedium (USB-stick) fysiek verwijderd tijdens de automatische herstart om een loop naar de setup te voorkomen.
